# Games

A collection of small standalone Python games built with [pygame](https://www.pygame.org/).

## Requirements

- Python 3.10+
- [pygame](https://www.pygame.org/)

```bash
pip install pygame
```

## Games

### [Nim](Nim/main.py)

Classic strategy game played under **misère rules**: players take turns removing one or more chips from a single group, and whoever is forced to take the last chip loses. Two-player, hot-seat.

```bash
python Nim/main.py
```

### [15 Puzzle](15_puzzle/15_game.py)

The sliding tile puzzle — arrange numbered tiles into order by sliding them into the empty slot. Shuffles into a solvable starting position on every launch.

```bash
python 15_puzzle/15_game.py
```

### [Snake](snake/main.py)

The classic snake game: eat food to grow, avoid running into yourself. Configurable snake block size.

```bash
python snake/main.py
```

### [BanderoGoose](BanderoGoose/main.py)

A side-scrolling runner game built during the GoIT marathon — dodge obstacles as a goose while the background scrolls by.

```bash
python BanderoGoose/main.py
```
